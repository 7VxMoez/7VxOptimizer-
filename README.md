## 🖥️ Dashboard — Command Center

The Dashboard is the main control center of MOEZ GAME BOOSTER. It brings your device status, GameLoop controls, graphics tools, joystick settings, backups, and community links into one place.

### Command Center

- **Anti Crash:** Dedicated ON/OFF session switch.
- **Kill GameLoop:** Stops detected GameLoop processes and its emulator service.
- **Refresh Status:** Refreshes device, GameLoop, backup, and joystick information.
- **Device Connection:** Shows ADB connection status and provides quick device connection.

### Live Status Cards

The dashboard displays four important status panels:

| Panel | Information |
|---|---|
| Device | ADB connection status |
| GameLoop | Emulator running status and VM profile |
| Save Backups | Number of available Active.sav backups |
| Joystick | Key-map status and four WASD speed values |
